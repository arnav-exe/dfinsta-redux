# Superseded documents

These describe the pipeline as it was **before 2026-08-08**, when the project decided
endpoints early from static evidence and corrected wrong decisions afterwards through a
reversal gate. That approach was abandoned and its machinery deleted; see
[`../DESIGN_EXPLORATION_FIRST.md`](../DESIGN_EXPLORATION_FIRST.md) for what replaced it
and why.

They are kept because they record **why things are shaped the way they are** — the four
inert patches that made every hook announce its own execution, the fabricated evidence
corpus, the gates that were complete and disconnected. That history is worth reading. The
*designs* in them are not current.

Nothing here is authoritative. Do not act on a command line, a module name or a stage
order taken from these files without checking it against the code first: they refer to
nine modules that no longer exist.

| file | what it was |
|---|---|
| `IMPLEMENTATION_STATE.md` | the detailed resume record, 2200 lines of accreted session history |
| `ROADMAP.md` | the single roadmap under the old approach |
| `SUBMISSION_CLIENT.md` | how a human answered the retirement and reversal gates |
| `WORKFLOW_REGISTRATION_DESIGN.md` | Temporal registration and the five-workflow topology |
